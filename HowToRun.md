# How to run TensorChess

Follow these steps from the repo root.

## Prerequisites
- Node.js 18+ (Vite 5 requires at least Node 18)
- npm (comes with Node)
- A browser with WebGL enabled to see the 3D view

## Install dependencies
```bash
npm install
```

## Start the dev server
```bash
npm run dev
```
Open the URL printed in the terminal (defaults to `http://localhost:5173`). Vite will hot-reload changes.

## Build for production
```bash
npm run build
```
This emits a static bundle to `dist/`.

## Preview the production build locally
```bash
npm run preview
```
Serves the built bundle (defaults to `http://localhost:4173`).
